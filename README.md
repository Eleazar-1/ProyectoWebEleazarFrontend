# Triply — Demo de proyecto DAW

Triply es una aplicación web diseñada para facilitar la organización de viajes entre varias personas. La idea es reunir en un mismo lugar toda la información necesaria para preparar un viaje: itinerario, actividades, participantes, presupuesto, gastos y decisiones del grupo.

Cada viaje tendrá su propio espacio compartido, donde los usuarios podrán añadir actividades, registrar gastos y votar entre diferentes opciones, como restaurantes, horarios o actividades.

El proyecto contará con un frontend, encargado de la interfaz y la interacción con el usuario, y un backend conectado a una base de datos para gestionar usuarios, viajes, gastos, votaciones e itinerarios.

Algunas funciones más avanzadas, como mapas, reservas y el cálculo automático de quién debe dinero a quién, se plantean como funcionalidades futuras.

## Archivos
- index.html — estructura de la web
- styles.css — diseño responsive
- script.js — navegación e interacciones de la demo

## Cómo ejecutarla
Abre `index.html` en el navegador.
